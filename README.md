# Category Counter App

A simple and elegant web application for counting items across multiple categories (A through F).

## Features

- **6 Categories**: Counter for categories A, B, C, D, E, and F
- **Increment/Decrement**: Easy-to-use + and - buttons for each category
- **Reset All**: Quickly reset all counters to zero
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Animated Interactions**: Smooth animations for better user experience
- **Keyboard Shortcuts**: Press Ctrl+R to reset all counters
- **Prevents Negative Values**: Counters cannot go below zero

## How to Use

1. Open `index.html` in your web browser
2. Click the **+** button to increment a category counter
3. Click the **−** button to decrement a category counter
4. Use the **Reset All Counters** button to set all counters back to zero
5. Use **Ctrl+R** keyboard shortcut for quick reset

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - JavaScript functionality and interactions

## Browser Compatibility

This app works in all modern web browsers including:
- Chrome
- Firefox
- Safari
- Edge

## Getting Started

Simply open the `index.html` file in any web browser to start using the app. No installation or setup required!
